# Comparation App

A sourcing agent for shoppers: **tell it what you need, it does the searching and the asking, and comes back with one ranked answer.** First market under test: car parts in Australia. The original idea, a new-versus-used deal finder, is recorded in `docs/idea-brief.md`.

Status: research phase. No app code yet.

## Layout

| Path | What lives here |
|---|---|
| `MORNING-BRIEF.md` | Start here. Where the research landed, the gap, research question, pipeline, methodology, decisions needed. |
| `docs/idea-brief.md` | The founder's idea, restated and scoped. |
| `research/prompts/` | The research briefs each overnight agent ran (re-runnable). |
| `research/findings/` | Raw findings — one file per brief. `second-pass/` checks them at the source; `third-pass/` covers the permission route, competitor teardown and car parts. |
| `research/synthesis/` | Literature review, gap analysis, research question. |
| `methodology/` | Methodology (with the validation plan), system pipeline, risk register. |
| `app/` | Empty until the build starts. |
